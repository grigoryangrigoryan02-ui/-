# 🎵 Հայ Ժամանց - Հայկական Ժամանցային Կայք

Բարի գալուստ Հայ Ժամանց կայք: Սա ամբողջական հայկական ժամանցային գործիքակազմ է, որը մտածված հայ մշակույթի շուրջ:

## 📋 Կայքի Բաժինները

### 🎵 Երաժշտություն
- Հայկական դասական երաժշտության ժամանակ
- 4 հայտնի հայ կազմ
- Audio player հարմարավետ նայումով

### 📝 Թեստեր
1. **Հայ Մշակույթ Թեստ** - Հայ մշակույթի մասին 5 հարց
2. **Հայ Պատմություն Թեստ** - Պատմական գիտելիքներ
3. **Հայ Լեզու Թեստ** - Լեզվական կանոններ
4. **Հայ Ճանապարհորդություն Թեստ** - Պատմական վայրեր

### 🧠 Ինտելեկտուալ Վիկտորինաներ
1. **Տրամաբանական Հարցեր** - Մաթեմատիկական հարցեր
2. **Ընդհանուր Գիտելիքներ** - Տարբեր հարցեր
3. **Գիտական Հարցեր** - Ֆիզիկա, քիմիա, կենսաբանություն
4. **Հայ Գրականություն** - Հայ գրողներ և ստեղծագործություն

## 🎨 Դիզայն

- **Թեմա:** Կապույտ գույնի շկալա (Professional Blue Theme)
- **Հարմարավետություն:** Լիովին արձագանքական (Mobile Friendly)
- **Հայերեն:** Ամբողջ կայքը հայերեն է

## 🔐 Ադմին Պանել

### Մուտք
- **Հասցե:** `admin.html`
- **Գաղտնաբառ:** `5`

### Ադմինական Գործառույթներ
1. **Ընդամենը** - Կայքի ընդհանուր վիճակ
2. **Օգտատերերի Կառավարում** - Օգտատերերի ցուցակ
3. **Երաժշտության Կառավարում** - Երաժշտական ստուդիա
4. **Թեստերի Կառավարում** - Թեստերի կառավարում
5. **Վիկտորինաների Կառավարում** - Վիկտորինաների կառավարում
6. **Կարգավորումներ** - Կայքի պարամետրեր
